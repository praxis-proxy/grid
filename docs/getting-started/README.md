# Getting Started

AI Grid Network (AGN) is a technical preview. Start with these pages, in
order:

1. [Technical preview scope and limitations](../technical-preview-scope.md):
   what AGN does and what the deployment owner supplies.
2. [Quickstart](quickstart.md): run a two-site grid on one Linux machine with
   kind, send a request through it, and clean up.

Then install AGN on your own clusters with the
[existing-cluster Helm installation](../installation/existing-clusters.md).

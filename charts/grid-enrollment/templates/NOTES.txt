  kubectl -n {{ .Release.Namespace }} get secret {{ .Values.ca.bundleSecretName }} -o jsonpath='{.data.ca\.crt}' | base64 -d

Security posture (read before using beyond dev):
  - This Helm-Secret path is the dev/interim posture. Key-separation (the signing
    key never reaches the gateway), secretRef-only BYO, and generate-if-absent
    idempotence hold even here.
  - Kubernetes Secrets are base64, not encrypted, unless the cluster has an etcd
    encryption provider. Enabling it is a prerequisite for holding the CA key
    this way. Verify it before production use.
  - GA gate for the CA signing key is a non-exportable KMS/HSM key, not a Secret.

{{- if eq $configSource "operator" }}

The Grid operator writes ConfigMap {{ include "praxis-gateway.configMapName" . }} (GridNetwork
gatewayRefs consumerConfig.enabled: true). The pod waits in ContainerCreating until
that ConfigMap exists. If the GridNetwork sets another consumerConfig.configMapName, set the
same name in praxisConfig.operator.configMapName.

NOTE: the operator's praxis.yaml has no caller authentication. Anything that reaches the
gateway can use inference, so keep the Service ClusterIP behind an authenticating front.

mTLS to backends: if the operator's praxis.yaml uses mutual_tls, it reads tls.crt, tls.key
and ca.crt from the GridNetwork's consumerConfig.tlsCertMountPath (default /etc/praxis/tls).
The chart mounts those files only when tls.enabled is true. Set:
  tls.enabled: true
  tls.existingSecret: the Secret with tls.crt and tls.key
  tls.caSecret: the Secret with ca.crt (leave empty if ca.crt is in existingSecret)
  tls.mountPath: the same path as tlsCertMountPath
{{- if not .Values.tls.enabled }}

tls.enabled is false, so no TLS files are mounted.
{{- end }}
